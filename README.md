
# Express Portfolio

INFR3120 Assignment 2

This is my personal portfolio website built using Node.js, Express and EJS.

## Pages
- Home
- About Me
- Projects
- Contact

## Technologies Used
- Node.js
- Express.js
- EJS
- Bootstrap
- Font Awesome
- CSS

## Running the Project

1. Install Node.js.
2. Open the project folder in a terminal.
3. Run `npm install`.
4. Run `npm start`.
5. Open http://localhost:3000
