# Express Portfolio


This is my personal portfolio website for Assignment 2. I built it using Node.js, Express and EJS.

The website has four pages where visitors can learn about me, see some of my projects and find my contact information.


## Pages

- **Home** - A short introduction and some of my interests.
- **About Me** - Information about my background, education and skills.
- **Projects** - Some projects I've worked on, including my first portfolio, Angular practice and networking labs.
- **Contact** - My email, GitHub and LinkedIn.




## Technologies Used

- Node.js and Express.js
- EJS for the pages and shared header/footer
- HTML and CSS
- Bootstrap for the layout and cards
- Font Awesome for icons
- JavaScript for updating the footer year



## How to Run

1. Install Node.js if it isn't already installed.
2. Open the project folder in VS Code.
3. Open the terminal and run `npm install`.
4. Run `npm start`.
5. Open `http://localhost:3000` in a browser.





## Project Structure

- `routes` - Contains the routes for the four pages.
- `views` - Contains the EJS pages and shared partials.
- `public` - Contains the CSS, JavaScript and project images.
- `app.js` - Main Express application setup.
